# GDSUN - Gestão de Usinas e Telecom

Sistema de gestão e mapeamento operacional de usinas solares fotovoltaicas (UGs), concessionárias locais de energia e provedores de internet/telecom.

## 🚀 Tecnologias Utilizadas
- **React 19**
- **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Lucide Icons**
- **XLSX (SheetJS)**

## 📦 Como Rodar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   cd SEU_REPOSITORIO
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse no navegador: `http://localhost:3000`

4. **Gerar build de produção:**
   ```bash
   npm run build
   ```

## 🌐 Como Fazer Deploy na Vercel

1. Suba este projeto para um repositório no seu **GitHub**.
2. Acesse [vercel.com](https://vercel.com) e faça login com seu GitHub.
3. Clique em **"Add New..."** > **"Project"**.
4. Selecione o repositório importado.
5. As configurações padrão do Vite já serão detectadas automaticamente:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
6. Clique em **"Deploy"**.
7. Pronto! Em menos de 1 minuto seu site estará online com HTTPS gratuito.
